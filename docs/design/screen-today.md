### 3.1 출발 시각 줄 (`rules.md` 11.2)
| 경우 | 표시 |
|---|---|
| 목표 도착 시각 있음, 출발 시각이 아직 안 지남 | "늦어도" + "07:52" + "출발" |
| 목표 도착 시각 있음, 출발 시각이 지남 | "지금 출발하면" + "08:50" + "도착" |
| 목표 도착 시각 없음 | "지금 출발하면" + "08:50" + "도착" |

- 출발 시각이 지나도 늦는 시간이나 주의 배지는 표시하지 않음 (2026-10-20 사용자 결정)

- 예상 도착 시각 = 지금 시각 + 총 소요 시간 (분 단위 올림, `rules.md` 2장)
- 화면에서 가장 큰 글자는 이 줄의 숫자 하나 (`DESIGN.md` 11.1)

### 4.1 대여소 행 (`station-row`)
| 행 | 내용 |
|---|---|
| 대여 | "대여 · {대여소 이름}", "도보 N분"(대여소까지, `toStationSeconds`), "자전거 N대"(`availableBikes`) |

## 5. 상태
| 상태 | 조건 | 표시 |
|---|---|---|
| 장소 미등록 | 저장된 장소가 2개 미만 | `empty-state`: "출발지와 도착지를 등록하면 오늘의 추천을 보여 드립니다" + `button-primary` "장소 등록"(SC-02로 이동). 머리 영역 없음 |
| 처음 불러오는 중 | 이번 화면에서 받은 결과가 없고 조회 중 | 기본 경로 카드 자리와 다른 경로 카드 자리 2개에 같은 모양의 `surface-indigo` 면을 먼저 표시 |
| 다시 불러오는 중 | 받은 결과가 있고 새로고침, 전환으로 조회 중 | 기존 카드 유지, 새로고침 버튼 비활성 |
| 정상 | `transit.status`가 `ok` | 1 ~ 4장 구성 |
| 경로 없음 | `transit.status`가 `no_result` | 기본 경로 자리에 `empty-state` 모양: "경로를 찾지 못했습니다" + `button-primary` "다시 시도". `pmOnly`가 있으면 그 아래 PM 전용 카드 |
| 운행 중인 대중교통 없음 | `transit.status`가 `out_of_service` (`rules.md` 3.4.5) | 기본 경로 자리에 `empty-state` 모양: "운행 중인 대중교통이 없습니다" + `button-primary` "다시 시도". `pmOnly`가 있으면 그 아래 PM 전용 카드 |
| 불러오기 실패, 이전 결과 있음 | `transit.status`가 `unavailable`이거나 서버에 연결하지 못함. 이번 화면에서 받은 결과가 있음 | 이전 결과 유지 + 맨 위 `badge-neutral` "N분 전 정보" + `toast` "경로를 불러오지 못했습니다" |
| 불러오기 실패, 이전 결과 없음 | 위와 같고 받은 결과가 없음 | 경로 없음과 같은 표시. `pmOnly`가 있으면 표시 |
| 재고 정보 없음 | `bikeMix.stockKnown`이 거짓 | 따릉이 포함 카드에 `badge-caution` "재고 정보가 없습니다" |
| 출발 시각이 지남 | 늦어도 출발해야 할 시각이 지금보다 앞섬 | 출발 시각 줄을 "지금 출발하면 HH:MM 도착"으로 바꿈 (3.1) |

- "N분 전" = 지금 시각 − 이전 결과의 `fetchedAt`, 분 단위 버림
- 따릉이 포함, 버스 전용 경로가 없으면 카드를 만들지 않으며 빈 자리 안내도 없음 (`DESIGN.md` 8장)
- 이전 결과는 화면 메모리에만 있음. 화면을 닫으면 사라짐 (`rules.md` 10장, `tech_stack.md` 6장)

## 6. 수단 구성 (`mode-chain`)
| 구간 (`legs[]`) | 칩 글자 | 칩 바탕, 글자색 |
|---|---|---|
| `walk`, `edge`가 `origin` 또는 `destination` | 도보 아이콘 + "도보 N분" | `mode-walk`, `ink` |
| `walk`, `edge`가 `null` (환승 도보) | 칩을 만들지 않음 | - |
| `bus` | 버스 아이콘 + 첫 번째 노선 이름(`vehicles[0].name`, 예: "606") | 첫 번째 노선의 버스 종류 색과 그 글자 (`DESIGN.md` 2.4.3) |
| `subway` | 지하철 아이콘 + 노선 이름(`vehicles[0].name`, 예: "2호선") | 첫 번째 노선의 지하철 노선 색과 그 글자 (`DESIGN.md` 2.4.2) |
| `bike` | 따릉이 아이콘 + "따릉이 N분"(`seconds`) | `mode-bike`, `ink-dark` |
| PM 전용 경로 (구간 없음) | 따릉이 아이콘 + "자전거 N분"(`totalSeconds`) | `mode-pm`, `ink-dark` |

- 칩 사이에 "→"를 두고 간격 `spacing.xs`. 한 줄을 넘치면 다음 줄로 이어짐
- 색과 함께 노선 이름을 글자로 표시. 표에 없는 노선, 종류는 `primary`, `ink` (`DESIGN.md` 2.4)

### 6.1 구간 펼쳐 보기 (권장 F-15)
- 카드 아무 곳이나 누르면 카드 아래쪽이 펼쳐지고, 다시 누르면 접힘. 펼친 영역의 "지도 보기" 버튼을 누를 때는 접히지 않음
- 펼친 영역: `leg-row` 목록(구간 순서대로, 행 사이 `spacing.xs`) + `button-ghost-sm` "지도 보기"(SC-04 `#map/{경로 종류}`로 이동)
- 카드마다 따로 펼침. 펼침 상태는 화면 메모리에만 두고, 새로고침, 출근 퇴근 전환, 다른 화면에서 돌아오면 모두 접힘
- 불러오는 중의 빈 카드는 펼치지 않음
- 키보드: 카드에 초점을 두고 Enter 또는 Space로 펼침, 접힘. 펼침 여부를 화면 낭독기에 알림(`aria-expanded`)

| 구간 (`legs[]`) | 첫 줄 | 둘째 줄 | 셋째 줄 |
|---|---|---|---|
| `walk` | 도보 아이콘 + "도보" | "{시작} → {끝}" | "N분 · N.Nkm" |
| `bus` | 버스 아이콘 + 노선 이름 모두(쉼표로 이음, 예: "606, 643") | "{승차 정류장} → {하차 정류장} · N개 정류장" | "N분 · 승차 대기 N분" |
| `subway` | 지하철 아이콘 + 노선 이름 모두 | "{승차역} → {하차역} · N개 역" | "N분 · 승차 대기 N분" |
| `bike` | 따릉이 아이콘 + "따릉이 N분" | "{대여 대여소} → {반납 대여소}" | "대여소까지 도보 N분, 대여·반납 N분, 자전거 N분, 반납 후 도보 N분" |
| PM 전용 경로 (구간 없음) | 따릉이 아이콘 + "자전거 N분" | "N.Nkm · 자전거 길 기준" | - |

- 행 전체를 구간의 수단 색으로 칠하고, 글자는 모든 줄이 그 색의 글자 (`DESIGN.md` 2.4). 수단 색은 6장 수단 구성과 같음
- 도보의 {시작}, {끝}
  | `edge` | 시작 | 끝 |
  |---|---|---|
  | `origin` | "출발지" | 다음 대중교통 구간의 승차 정류장. 없으면 "도착지" |
  | `destination` | 앞 대중교통 구간의 하차 정류장. 없으면 "출발지" | "도착지" |
  | `null` (환승 도보) | 앞 대중교통 구간의 하차 정류장 | 다음 대중교통 구간의 승차 정류장 |
  - 앞, 뒤가 따릉이 구간이면 그쪽은 대여소 이름 대신 "따릉이 반납 대여소", "따릉이 대여 대여소"
- N개 정류장, N개 역 = `stops` 수 − 1
- 시간은 분 단위 올림, 거리는 100m 단위 반올림해 소수 첫째 자리 (`screens.md` 3.3)
- 대여·반납 N분 = (`rentSeconds` + `returnSeconds`)를 분 단위 올림
- 기본 경로의 출발 도보, 도착 도보 조회에 실패한 경우(`edgeWalkKnown` 거짓)에는 두 도보 행이 없음
- 버스, 지하철 구간 행 바로 아래에 노선마다 실시간 위치 행(`leg-row`)을 둠 (권장 F-26, `api_spec.md` 4.10, 2026-10-20 사용자 결정). 펼친 영역에만 표시하고 접힌 카드는 바꾸지 않음
  - 위치 행은 아이콘 없이 노선 이름과 위치 문구 칩(`position-chip`) 한 줄 (예: "643 [5정거장 전]", "2호선 [도착]")
  - 위치 행 바탕은 그 노선의 수단 색, 노선 이름은 그 색의 글자. 위치 문구 칩은 `position-surface` 바탕에 `position-text` 글자 (`DESIGN.md` 2.4.1)
  | `positions[].status` | 버스 | 지하철 |
  |---|---|---|
  | `live`, `stopsAway` 1 이상 | "N정거장 전" | "N역 전" |
  | `live`, `stopsAway` 0 | "도착" | "도착" |
  | `timetable` | - | "N분 후 도착 예정". N = (`nextDeparture` − 지금) ÷ 60, 분 단위 올림. 1분마다 다시 계산하고, `nextDeparture`가 지나면 행을 만들지 않음 |
  | `none` | "정보 없음" | "정보 없음" |
  | `unknown` | 행을 만들지 않음 | 행을 만들지 않음 |
  - 버스, 지하철 구간이 있는 카드는 펼친 영역의 구간 목록 아래(지도 보기 버튼 위)에 "위치는 HH:MM 기준" 한 줄 (`link-sm`, `ink-secondary`). HH:MM은 응답의 `fetchedAt`을 분 단위 버림
  - 문구 결정: 2026-10-20 사용자 결정 (Q-10)

## 7. 조회와 시각 갱신
- 조회 시점: 화면을 열 때, 새로고침, 출근 퇴근 전환
- 요청: `POST /api/recommend`. 지금 방향에 맞춰 출발지, 도착지 좌표를 보냄. 지금 방향의 목표 도착 시각이 있으면 기준 도착 시각(목표 도착 시각 − 여유 시간)도 보냄 (`api_spec.md` 4.1)
- 화면이 열려 있는 동안 1분마다 시각 표시(출발 시각 줄, 예상 도착, "N분 전")만 다시 계산. 다시 조회하지 않음
