## 1. 구성 (위에서 아래 순서)
| 순서 | 구역 | 요소 | 컴포넌트 |
|---|---|---|---|
| 1 | 머리 | 뒤로 가기 버튼(이름 "뒤로 가기", SC-01로 이동, 5장), 제목 "설정" | `top-bar`, `icon-button` |
| 2 | 장소 | 구역 제목 "장소", 출발지 행, 도착지 행 | `list-row` |
| 3 | 도착 목표 | 구역 제목 "도착 목표", 출근 목표 도착 시각 행, 퇴근 목표 도착 시각 행, 여유 시간 행 | `list-row` |
| 4 | 방향 | 구역 제목 "방향", 출근 퇴근 전환 기준 행 | `list-row` |
| 5 | 저장 정보 | "저장 정보 모두 지우기" | `button-ghost` |
| 6 | 저장 | 화면 아래쪽. 4장 | `button-primary` "저장" |

- 구역 제목은 `link-sm`, `ink-secondary`. 구역 사이는 `spacing.xxl`, 행 사이는 `spacing.xs`

## 2. 행
| 행 | 첫 줄 (`body`) | 둘째 줄 (`link-sm`, `ink-secondary`) | 누르면 |
|---|---|---|---|
| 출발지 | 장소 이름 (예: "집"). 없으면 "출발지 등록" | 장소 이름(키워드로 고른 장소이고 첫 줄 이름과 다를 때만). 그 아래 도로명 주소(없으면 지번 주소). 없으면 "도로명 또는 지번 주소로 등록합니다" | SC-03 `#place/origin` |
| 도착지 | 장소 이름 (예: "회사"). 없으면 "도착지 등록" | 출발지와 같은 방식 | SC-03 `#place/destination` |
| 출근 목표 도착 시각 | "출근 목표 도착 시각" + 오른쪽에 값 "09:00" 또는 "설정하지 않았습니다" | "{출발지 이름} → {도착지 이름}". 장소가 없으면 "출발지 → 도착지" | 3.1 |
| 퇴근 목표 도착 시각 | "퇴근 목표 도착 시각" + 값 | "{도착지 이름} → {출발지 이름}". 장소가 없으면 "도착지 → 출발지" | 3.1 |
| 여유 시간 | "여유 시간" + 값 "10분" | "출발 시각을 이만큼 앞당겨 알려 드립니다" | 3.2 |
| 출근 퇴근 전환 기준 | "출근 퇴근 전환" + 값 "14:00 전 출근" 또는 "14:00 전 퇴근" | "앱을 연 시각에 따라 방향을 정합니다" | 3.3 |

- 행에 보이는 값은 저장하지 않은 값까지 포함한 지금 화면의 값
- 시각 값의 "14:00"은 `rules.md` 12장 `DIRECTION_SWITCH_TIME`
- 여유 시간 기본값은 `rules.md` 12장 `MARGIN_SECONDS`

## 3. 모달
- 모두 화면 아래쪽에서 올라오는 선택 목록(`modal`, `DESIGN.md` 7.6). 제목은 `heading-sm`
- 모달에서 고른 값은 화면의 값만 바꾸며 기기에 저장하지 않음. 저장은 4장
- 모달 바깥을 누르거나 뒤로 가기를 누르면 값을 바꾸지 않고 닫음

### 3.1 목표 도착 시각
| 순서 | 요소 | 내용 | 컴포넌트 |
|---|---|---|---|
| 1 | 제목 | "출근 목표 도착 시각" 또는 "퇴근 목표 도착 시각" | - |
| 2 | 시각 입력 | 누르면 휴대폰의 시각 고르기 창이 열리는 입력 칸. 24시간제 `HH:MM`. 지금 값이 있으면 그 값, 없으면 비어 있음 | `text-input` 모양 |
| 3 | 확인 | 고른 시각을 화면 값에 넣고 닫음. 입력이 비어 있으면 비활성 | `button-primary` "확인" |
| 4 | 설정하지 않기 | 화면 값을 "설정하지 않았습니다"로 바꾸고 닫음 | `button-ghost` "설정하지 않기" |

- 시각 고르기 창은 휴대폰 기본 기능 사용. 사용자가 글자로 시각을 입력하지 않음 (2026-10-20 사용자 결정)

### 3.2 여유 시간
- 제목: "여유 시간"
- 선택지: "0분", "5분", "10분", "15분", "20분", "30분" (`list-row`, 2026-10-20 사용자 확인)
- 지금 값의 행에 확인 아이콘과 화면 낭독기용 "선택되었습니다"
- 행을 누르면 화면 값을 바꾸고 닫음

### 3.3 출근 퇴근 전환 기준
- 제목: "출근 퇴근 전환"

| 선택지 (`list-row`) | 첫 줄 | 둘째 줄 |
|---|---|---|
| 출근/퇴근 (기본) | "14:00 전 출근" | "14:00 이후 퇴근" |
| 퇴근/출근 | "14:00 전 퇴근" | "14:00 이후 출근" |

- 행을 누르면 화면 값을 바꾸고 닫음 (`rules.md` 9장, `frontend/CLAUDE.md` 4.3 `directionMode`)

### 3.4 저장 정보 모두 지우기 (F-12)
| 순서 | 요소 | 내용 | 컴포넌트 |
|---|---|---|---|
| 1 | 제목 | "저장 정보를 모두 지웁니다" | - |
| 2 | 본문 | "장소와 설정이 이 기기에서 지워지며 되돌릴 수 없습니다" | `body` |
| 3 | 취소 | 닫음 | `button-ghost` "취소" |
| 4 | 모두 지우기 | `frontend/CLAUDE.md` 4.1의 키를 모두 지우고 SC-01(장소 미등록 상태)로 이동. 저장하지 않은 값도 함께 버림 | `button-caution` "모두 지우기" |

### 3.5 저장하지 않고 나가기
| 순서 | 요소 | 내용 | 컴포넌트 |
|---|---|---|---|
| 1 | 제목 | "저장하지 않은 변경 사항이 있습니다" | - |
| 2 | 계속 수정 | 닫고 설정 화면에 머묾 | `button-primary` "계속 수정" |
| 3 | 나가기 | 바꾼 값을 버리고 SC-01로 이동 | `button-ghost` "저장하지 않고 나가기" |

## 4. 저장 (2026-10-20 사용자 결정)
| 항목 | 내용 |
|---|---|
| 대상 | 출근, 퇴근 목표 도착 시각, 여유 시간, 출근 퇴근 전환 기준 |
| 활성 | 저장된 값과 다른 값이 하나라도 있을 때. 아니면 `button-disabled` |
| 동작 | 바꾼 값을 한꺼번에 기기에 저장(`frontend/CLAUDE.md` 4.3), `toast` "저장했습니다" |
| 장소 | 저장 버튼 대상이 아님. 장소는 SC-03의 "저장"으로 따로 저장 |

## 5. 나가기
| 행동 | 바꾼 값이 없음 | 저장하지 않은 값이 있음 |
|---|---|---|
| 뒤로 가기 (SC-01로) | 바로 SC-01로 이동 | 3.5 확인 창 |
| 장소 행 (SC-03으로) | SC-03으로 이동 | 바꾼 값을 화면 메모리에 둔 채 SC-03으로 이동. 돌아오면 그대로 이어서 보임 |
