| 항목 | 내용 |
|---|---|

| 기능 | F-01 |

- 해당 칸이 비어 있으면 새로 등록, 저장된 장소가 있으면 수정

## 1. 구성 (위에서 아래 순서)
| 순서 | 요소 | 내용 | 컴포넌트 |
|---|---|---|---|
| 1 | 머리 | 뒤로 가기 버튼(이름 "뒤로 가기", SC-02로 이동), 제목 "출발지" 또는 "도착지" | `top-bar`, `icon-button` |
| 2 | 지금 장소 | 수정일 때만. 이름(`body`), 장소 이름(첫 줄 이름과 다를 때만), 도로명 주소(`link-sm`, `ink-secondary`). 누를 수 없음 | `list-row` |
| 3 | 주소, 장소 검색 | 입력 칸, 그 아래 안내 문구, 오른쪽 "검색" 버튼 | `text-input`, `button-ghost` |
| 4 | 후보 | 검색 결과 최대 10개 (2장) | `list-row` |
| 5 | 더 보기 | 다음 쪽이 있을 때만(`isEnd`가 거짓). 다음 쪽 후보를 아래에 이어 붙임 | `button-ghost` "더 보기" |
| 6 | 이름 | 장소 이름 입력 칸 (3장) | `text-input` |
| 7 | 저장 | 화면 아래쪽. 4장 | `button-primary` "저장" |
| 8 | 장소 삭제 | 수정일 때만. 저장 버튼 아래 | `button-ghost` "장소 삭제" |

## 2. 주소, 장소 검색과 후보
- 입력 칸 예시 문구: "주소 또는 장소 이름" (`ink-secondary`)
- 안내 문구: "예: 테헤란로 152, 강남역, 정부서울청사" (`link-sm`, `ink-secondary`)
- "검색" 버튼이나 키보드의 입력 완료로 검색. 글자를 입력할 때마다 검색하지 않음
- 요청: `POST /api/address/search` (`query`, `page`, 다음 쪽이면 `source`). 검색어는 주소(URL)에 넣지 않음
- 후보 행 (`DESIGN.md` 7.5)
  | 후보 | 첫 줄 (`body`) | 둘째 줄 (`link-sm`, `ink-secondary`) |
  |---|---|---|
  | 주소 (`source`가 `address`) | 도로명 주소(`roadAddress`). 없으면 대표 주소(`addressName`) | 지번 주소(`jibunAddress`)와 건물 이름(`buildingName`)을 " · "로 이음. 없는 값은 뺌 |
  | 장소 (`source`가 `place`) | 장소 이름(`placeName`) | 도로명 주소. 없으면 지번 주소 |
- 후보를 누르면 그 행을 선택 상태로 표시 (확인 아이콘, 화면 낭독기용 "선택되었습니다"). 다른 후보를 누르면 선택이 옮겨감
- 새로 검색하면 후보와 선택을 비움

## 3. 이름
- 입력 칸 위 이름표 "이름" (`link-sm`, `ink-secondary`)
- 예시 문구: 출발지 "예: 집", 도착지 "예: 회사"
- 앞뒤 공백을 지운 뒤 1자 이상 20자 이하
- 수정일 때는 지금 이름을 채워 둠
- 장소 후보를 고를 때 이름 칸이 비어 있으면 장소 이름의 앞 20자로 채움. 사용자가 고칠 수 있음 (D-32)

## 4. 저장과 삭제
| 동작 | 조건, 처리 |
|---|---|
| 저장 활성 | 주소가 정해짐(새 후보를 골랐거나, 수정일 때 지금 주소) + 이름 조건 충족. 아니면 `button-disabled` |
| 저장 | 고른 후보의 `addressName`, `roadAddress`, `jibunAddress`, `placeName`, `x`, `y`와 이름을 해당 칸에 저장 (`frontend/CLAUDE.md` 4.2) 후 SC-02로 이동 |
| 장소 삭제 | `modal`: 제목 "장소를 삭제합니다", 본문 "{이름} 장소가 이 기기에서 지워집니다", `button-ghost` "취소", `button-caution` "삭제". 삭제하면 SC-02로 이동 |

## 5. 상태
| 상태 | 조건 | 표시 |
|---|---|---|
| 검색 전 | 아직 검색하지 않음 | 후보 자리 비움 |
| 입력 오류 | 공백을 뺀 검색어가 2자 미만이거나 100자 초과 (`api_spec.md` 3.1). 서버에 보내지 않음 | 입력 칸 아래 `caution` 아이콘과 `caution` 글자 "2자 이상 입력해 주십시오" 또는 "100자 이하로 입력해 주십시오" |
| 검색 중 | 응답을 기다림 | "검색" 버튼 비활성, 후보 자리에 "검색하고 있습니다" (`link-sm`, `ink-secondary`) |
| 후보 있음 | `status`가 `ok` | 2장 후보 행 |
| 후보 없음 | `status`가 `no_result` | 후보 자리에 "주소나 장소를 찾지 못했습니다. 검색어를 확인해 주십시오" (`body`, `ink-secondary`) |
| 검색 실패 | `status`가 `unavailable`이거나 서버에 연결하지 못함 | `toast` "주소를 검색하지 못했습니다. 다시 시도해 주십시오". 입력한 검색어는 유지 |
