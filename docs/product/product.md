# 서비스 정의서: 출퇴근 대중교통, PM 경로 추천 서비스

## 0. 문서 정보
- 상태: 방향성 정의 단계 (서비스의 정체성, 목표, 범위만 다룸)
- 작성일: 2026-10-19
- 최종 수정: 2026-10-19 (추천 결과 4종 경로 반영)
- 서비스 이름: 미정 (`docs/masterplan.md` 6.2)
- 서비스 운영 전제

  - 수익 구조는 고려하지 않음. 매일의 편의성과 경로 비교의 정확도에만 집중
  - 경로는 카카오맵 API(대중교통, 도보, 자전거 경로)만 사용. 따릉이 재고는 서울 공공 데이터 사용

## 1. 서비스 정체성

### 1.1 한 문장
> 저장해 둔 출퇴근길의 카카오맵 추천 경로를 기준으로, 첫, 마지막 구간을 따릉이로 바꾼 경로와 버스만, PM만 타는 경로까지 함께 보여 주고 앱을 여는 순간 출발 시각을 알려 주는 서비스

### 1.2 풀어 쓴 정의
- 출퇴근 출발지와 도착지를 주소로 한 번 저장해 두면
- 앱을 열 때마다 카카오맵 추천 경로(기본 경로)와, 첫, 마지막 도보 구간을 PM으로 바꾸면 줄어드는 시간을 보여 주고
- 집에서 첫 역까지, 마지막 역에서 목적지까지를 따릉이로 바꾼 경로(재고 확인), 버스만 타는 경로, PM만으로 가는 경로를 함께 비교해
- 경로별로 늦어도 출발해야 할 시각을 알려 주는 서비스

### 1.3 정체성을 이루는 두 가지 축
| 축 | 의미 | 일반 길찾기와의 차이 |
|---|---|---|
| 반복 경로 특화 | 출퇴근 장소를 한 번 저장하면 매일 다시 입력하지 않음 | 일반 길찾기는 매번 출발지, 도착지 입력 |
| 대중교통과 PM의 비교 (주요 차별점) | 카카오 기본 경로를 기준으로 따릉이 포함, 버스 전용, PM 전용 경로를 한 화면에서 비교 | 대중교통 길찾기는 첫, 마지막 구간을 도보, 버스로만 안내하고, 자전거 길찾기는 대중교통과 함께 비교하지 않음 |

### 1.4 엘리베이터 피치
지하철역까지 걸어서 20분, 버스를 타도 배차를 기다려야 하는 사람을 위한 서비스
집과 회사를 한 번만 저장하면 앱을 열 때마다 카카오맵 추천 경로와 함께, 역까지 따릉이로 가는 경로, 버스만 타는 경로, 자전거로만 가는 경로를 나란히 보여 주고 각각 언제 나가야 하는지 알려 줌

## 2. 추진 배경
- 대중교통 출퇴근 시간의 상당 부분은 집에서 첫 역까지, 마지막 역에서 목적지까지의 구간이 차지함. 이 구간을 걷거나 마을버스를 기다리며 보냄
- 공유 자전거, 공유 킥보드 같은 개인형 이동수단(PM)으로 이 구간을 줄일 수 있지만, 대중교통 길찾기는 PM을 섞어 주지 않고 PM 길찾기는 대중교통과 비교해 주지 않음
- 그 결과 사용자는 대중교통 앱, 자전거 앱, 따릉이 앱을 따로 보고 머릿속으로 합쳐 비교하거나, 비교를 포기하고 늘 하던 대로 이동함
- 문제와 대상, 해결 방향의 상세: `PTS.md`

## 3. 대상 사용자 요약
- 대중교통으로 출퇴근, 통학하며 첫 역까지, 마지막 역에서 목적지까지 걷거나 버스를 타는 사람
- 매일 같은 출발지, 도착지를 오가는 사람
- 정해진 도착 시각(출근, 수업, 교대 인수인계)이 있는 사람
- 상세 정의: `PTS.md` 2장, 예시 사용자: `persona.md`

## 4. 제공 가치

### 4.1 핵심 가치
| 가치 | 내용 |
|---|---|
| 입력 없는 확인 | 앱을 열면 저장한 장소로 오늘의 추천이 바로 보임 |
| 기준이 있는 비교 | 카카오맵 추천 경로를 기준으로 다른 경로가 몇 분 빠르거나 느린지 보여 줌 |
| PM의 효과를 바로 확인 | 기본 경로만 보더라도 첫, 마지막 도보 구간을 PM으로 바꾸면 줄어드는 시간을 함께 표시 |
| 헛걸음 방지 | 따릉이는 대여 가능한 자전거와 반납할 자리가 있는 대여소만 골라 안내 |
| 늦지 않는 출발 | 목표 도착 시각에서 거꾸로 계산한 "늦어도 출발해야 할 시각" 제공 |

### 4.2 사용자가 받는 결과 (최대 4개 경로)
| 경로 | 내용 | 표시 |
|---|---|---|
| 기본 경로 | 카카오맵 추천 경로 원본과 PM으로 바꾸면 줄어드는 시간 | 항상 (1순위) |
| 따릉이 포함 경로 | 첫, 마지막 구간을 따릉이로 바꾼 경로, 또는 전 구간 따릉이 경로. 대여소와 대여 가능 대수 포함 | 조건을 만족할 때 (`functions.md` F-05) |
| 버스 전용 경로 | 버스만 타는 경로 중 가장 빠른 경로 | 버스 경로가 있고 기본 경로와 다를 때 |
| PM 전용 경로 | 출발지에서 도착지까지 자전거 경로 | 조회되면 |

- 경로마다 예상 도착 시각, 총 소요 시간, 수단 구성, 추천 이유, 늦어도 출발해야 할 시각을 함께 표시

## 5. 서비스 원칙
- 열면 바로 답: 매일 하는 입력은 없음. 장소 등록은 처음 한 번
- 기준은 카카오맵 추천 경로: 기본 경로를 맨 위에 두고, 다른 경로는 기본 경로와의 차이로 보여 줌
- 추천에는 항상 이유: 경로마다 특징과 근거를 함께 표시
- 선택지 압축: 가능한 조합을 늘어놓지 않고 성격이 다른 경로 최대 4개만 표시
- 결정은 사용자에게: 서비스는 비교 근거를 제시하고, 실제로 어떤 경로를 탈지는 사용자가 결정
- 모르면 모른다고 표시: 받지 못한 정보는 추측으로 채우지 않고 "정보 없음"으로 알림
- 위치 최소화와 기기 보관
  - 출발지, 도착지 주소와 좌표는 사용자 기기에만 보관하고, 사용자가 언제든 모두 지울 수 있음
  - 서버는 경로 조회에 필요한 좌표를 외부 서비스에 전달하는 중계만 하고, 저장하거나 기록에 남기지 않음
  - 예외: 경로 지도(권장 F-16)는 브라우저가 카카오 지도를 직접 불러오므로 카카오가 지도에 보이는 지역을 알 수 있음 (2026-10-20 사용자 허용)
  - 실시간 위치를 추적하지 않음
- PM은 이동 수단으로만 다룸: 킥보드처럼 이용 가능 여부를 알 수 없는 수단은 표시하지 않고, 이동 속도가 빨라지는 것으로만 계산

## 6. 범위

### 6.1 범위 안
| 구분 | 내용 |
|---|---|
| 대중교통 경로 | 카카오맵 대중교통 경로 API가 주는 버스, 지하철 경로 (기본 경로, 버스 전용 경로) |
| 따릉이 대체 구간 | First mile(출발지 → 첫 지하철 승차역), Last mile(마지막 지하철 하차역 → 도착지). 그 사이의 도보, 버스 포함. 조건에 따라 전 구간 |
| PM 전용 | 출발지 → 도착지 자전거 경로 |
| 킥보드 | 기본 경로의 첫, 마지막 도보 구간을 바꿀 때 줄어드는 시간 계산에만 사용 |
| 따릉이 지역 | 서울 (대여소가 있는 곳) |
| 입력 | 출발지, 도착지의 지번 또는 도로명 주소 |
| 이동 목적 | 출근, 퇴근, 통학 (매일 반복되는 이동) |
| 사용 환경 | 휴대폰 웹 브라우저 (홈 화면에 추가해 앱처럼 사용) |

### 6.2 범위 밖
- 중간 환승 구간의 PM 대체
- 실시간 버스, 지하철 정보를 소요 시간, 출발 시각에 반영하는 것 (위치 표시는 권장 F-26)
- 킥보드의 위치, 이용 가능 여부
- 서울 외 지역의 공공자전거
- 실시간 위치 추적
- 회원가입, 로그인, 서버에 개인 정보 보관
- 택시, 자가용
- 수익 구조

## 7. 목표와 성공 기준
| 목표 | 확인 방법 |
|---|---|
| 매일 아침 결정이 빨라짐 | 앱을 열고 탈 경로를 정하기까지 별도 입력이 없음. 다른 교통 앱, 따릉이 앱을 함께 열지 않고 결정 가능 |
| PM의 효과를 보여 줌 | 기획자 본인의 출퇴근에서 따릉이 포함 경로가 표시된 날의 비율과 기본 경로 대비 시간 차이 |
| 추천을 믿고 따를 수 있음 | 고른 경로의 실제 도착 시각이 목표 도착 시각 안에 드는 비율 |
| 헛걸음이 없음 | 안내받은 대여소에 자전거가 없거나 반납할 자리가 없었던 횟수 |
| 위치를 넘기지 않음 | 서버 로그와 저장소에 주소, 좌표가 남지 않음 |

- 1차 근거는 기획자 본인의 실사용 결과. 측정 방법의 세부는 `docs/masterplan.md`의 통합 검증 단계에서 정함

## 8. 알려진 한계와 대응 방향
| 한계 | 대응 방향 |
|---|---|
| 실시간 도착 정보가 없어 배차 대기 시간이 카카오 소요 시간에 반영된 만큼만 들어감 | 출발 시각 계산에 여유 시간을 두고, 반영 여부를 데이터 확인 단계에서 확인 (`docs/tech/datasource.md`) |
| 킥보드는 이용 가능 여부를 알 수 없음 | 절감 시간만 보여 주고 사용자가 판단하도록 둠 |
| PM 전용 경로는 대여, 반납, 재고를 반영하지 않은 자전거 이동 시간 | 경로 이름과 이유에 "자전거 길" 기준임을 표시 |
| 평균 속도 기준이라 개인의 걸음, 자전거 속도와 다를 수 있음 | 경로 추천이 안정된 뒤 출발, 도착 기록과 개인 보정을 고려 (권장 기능) |
| 카카오 경로 API의 하루 무료 사용량이 정해져 있음 | 바뀌지 않는 경로 정보는 저장해 두고 다시 쓰는 방식으로 호출 수를 줄임 (`docs/tech/tech_stack.md`) |
| 기기에만 보관하므로 기기를 바꾸면 저장 정보가 이어지지 않음 | 사용자가 직접 내보내고 가져올 수 있도록 함 (권장 기능) |
