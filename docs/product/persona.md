## 예시 사용자 1: 정다은

### 인적사항
| 항목 | 내용 |
|---|---|
| 이름 | 정다은 |
| 성별 | 여 |
| 나이 | 31세 |
| 직업 | 마케팅 대행사 대리 (강남역 인근 사무실) |
| 거주 | 마포구 망원동 (1인 가구) |
| 디지털 UI 친숙도 | 높음. 교통, 날씨 앱을 여러 개 설치해 사용 중 |

### 출퇴근 정보
- 출근 경로 후보
  | 후보 | 구성 | 평소 소요 | 특징 |
  |---|---|---|---|
  | A. 지하철 환승 | 도보 7분 → 망원역 6호선 → 합정역 2호선 환승 → 강남역 → 도보 5분 | 약 58분 | 가장 예측 가능하지만 가장 오래 걸림 |
  | B. 버스 + 9호선 급행 | 도보 3분 → 집 앞 정류소 버스 → 당산역 → 9호선 급행 → 신논현역 → 도보 8분 | 약 52분 | 버스를 바로 타면 가장 빠르고, 놓치면 가장 늦음 |
  | C. 따릉이 + 9호선 급행 | 망원동 대여소 따릉이 → 당산역 대여소 반납 → 9호선 급행 → 신논현역 → 도보 8분 | 약 50분 | 날씨가 좋고 자전거가 있을 때만 가능 |
- 퇴근: 18:00 ~ 19:30 사이로 일정하지 않음. 정해진 도착 시각은 없고 가장 빨리 집에 가는 경로를 원함

### 서비스를 사용할 근거
- 사용 목적: 매일 아침 세 경로 중 가장 빠른 경로를 빨리 정하고, 9시 정시 출근을 지키기 위함
- 상황: 출근 준비를 하면서 버스 앱, 지하철 앱, 따릉이 앱, 날씨 앱을 번갈아 확인. 지난주 버스를 2분 차이로 놓쳐 10분 지각
- 심리: '버스를 바로 타면 제일 빠른데, 놓치면 지각이라 매번 도박하는 느낌'

## 예시 사용자 2: 김도윤

### 인적사항
| 항목 | 내용 |
|---|---|
| 이름 | 김도윤 |
| 성별 | 남 |
| 나이 | 22세 |
| 직업 | 대학생 3학년 (성동구 소재 대학, 왕십리 인근 캠퍼스) |
| 거주 | 광진구 자양동 (자취) |
| 디지털 UI 친숙도 | 높음 |
| 등교 시각 | 요일마다 다름. 월, 수 09:00 / 화, 목 10:30 / 금 13:00 |

### 출퇴근 정보
- 등교 경로 후보
  | 후보 | 구성 | 평소 소요 | 특징 |
  |---|---|---|---|
  | A. 지하철 | 도보 8분 → 건대입구역 2호선 → 한양대역 → 도보 7분 | 약 25분 | 날씨와 관계없이 안정적. 교통비 발생 |
  | B. 따릉이 직행 | 집 근처 대여소 따릉이 → 학교 앞 대여소 반납 | 약 22분 | 정기권이 있어 추가 비용 없음. 아침에 집 근처 대여소가 비어 있을 때가 많음 |
  | C. 버스 | 도보 3분 → 자양동 정류소 버스 → 학교 앞 정류소 → 도보 3분 | 약 25분 | 배차 간격 약 10분 |
- 하교: 수업이 끝나는 시각이 요일마다 다르고 정해진 도착 시각이 없음. 따릉이를 가장 선호

### 서비스를 사용할 근거
- 사용 목적: 따릉이를 최대한 활용하되, 비가 오거나 자전거가 없을 때 지각하지 않을 수단으로 빨리 바꾸기 위함
- 상황: 1교시가 있는 날 대여소에 갔다가 자전거가 없어 근처 대여소를 찾다 지각. 비가 올지 몰라 따릉이를 탔다가 비를 맞은 적도 있음
- 심리: '따릉이 있으면 공짜에 제일 빠른데, 없으면 걸어간 시간만 날림'

## 예시 사용자 3: 이수진

### 인적사항
| 항목 | 내용 |
|---|---|
| 이름 | 이수진 |
| 성별 | 여 |
| 나이 | 38세 |
| 직업 | 종합병원 병동 간호사 (양천구 목동), 3교대 근무 |
| 거주 | 강서구 화곡동 (배우자, 자녀 1명) |
| 디지털 UI 친숙도 | 보통. 자주 쓰는 앱만 쓰며 설정이 복잡한 앱은 쓰다 그만둠 |
| 출근 시각 | 근무조마다 다름. 인수인계 20분 전 도착이 원칙 |

- 근무조와 목표 도착 시각
  | 근무조 | 근무 시간 | 목표 도착 시각 | 이동 시간대의 특징 |
  |---|---|---|---|
  | 데이 | 07:00 ~ 15:30 | 06:40 | 이른 아침이라 버스 배차 간격이 김 |
  | 이브닝 | 14:30 ~ 23:00 | 14:10 | 낮 시간이라 수단 선택 폭이 가장 넓음 |
  | 나이트 | 22:30 ~ 다음 날 07:30 | 22:10 | 밤 이동. 퇴근은 다음 날 아침 출근 시간대 |
- 근무표는 한 달 단위로 나오며, 같은 주에도 근무조가 바뀜

### 출퇴근 정보
- 출근 경로 후보
  | 후보 | 구성 | 평소 소요 | 특징 |
  |---|---|---|---|
  | A. 버스 직행 | 도보 4분 → 화곡동 정류소 버스 → 병원 앞 정류소 → 도보 2분 | 약 25분 | 환승 없음. 이른 아침에는 배차 간격 12 ~ 15분 |
  | B. 지하철 | 도보 10분 → 화곡역 5호선 → 목동역 → 도보 10분 | 약 30분 | 배차가 짧아 기다림이 적지만 걷는 시간이 김 |
  | C. 따릉이 직행 | 집 근처 대여소 따릉이 → 병원 근처 대여소 반납 | 약 20분 | 이브닝 근무 출근처럼 낮 시간에만 이용 |
- 퇴근: 데이 근무 15:30, 이브닝 근무 23:00(늦은 밤, 배차 간격이 김), 나이트 근무 다음 날 07:30(아침 출근 시간대)

### 서비스를 사용할 근거
- 사용 목적: 이른 아침과 늦은 밤처럼 차를 한 대 놓치면 크게 늦어지는 시간대에 놓치지 않고 탈 수 있는 경로와 출발 시각을 알기 위함
- 상황: 데이 근무 날 버스를 한 대 놓쳐 인수인계에 늦을 뻔함. 근무조가 자주 바뀌어 출발 시각을 매번 다시 계산
- 심리: '인수인계에는 절대 늦으면 안 되니, 몇 시 몇 분에 나가면 되는지만 정확히 알려 줬으면'
