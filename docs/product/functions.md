# 기능 명세서

## 0. 문서 정보
- 작성일: 2026-10-19
- 최종 수정: 2026-10-19 (추천 결과를 4종 경로로 재구성)
- 목적: 서비스에 수록할 기능을 정하고, 지향점 충족도와 구현 난이도를 기준으로 필수, 권장, 불요로 분류
- 기능의 동작은 사용자 관점의 대략적인 수준만 기술. 계산 규칙은 `rules.md`, 화면 구성은 디자인 문서, 기술 방식은 `docs/tech/tech_stack.md`에서 다룸

### 0.1 서비스 개요
- 출퇴근 출발지, 도착지를 주소로 한 번 등록하면, 앱을 열 때마다 아래 경로를 최대 4개 보여 줌
  | 경로 | 내용 |
  |---|---|
  | 기본 경로 | 카카오맵 추천 경로 원본. 첫, 마지막 도보 구간을 PM으로 바꿀 때 줄어드는 시간을 함께 표시 |
  | 따릉이 포함 경로 | 첫, 마지막 구간을 따릉이로 바꾼 경로. 조건을 만족할 때만 표시 |
  | 버스 전용 경로 | 카카오 추천 경로 중 버스만 타는 최단 경로 |
  | PM 전용 경로 | 출발지에서 도착지까지 자전거 경로 |
- 대중교통 경로에 PM 선택지를 더해 함께 비교하는 것이 주요 차별점

### 0.2 결정 사항 (2026-10-19 사용자 결정)
| 항목 | 결정 |
|---|---|
| 경로 출처 | 대중교통 경로는 카카오맵 대중교통 경로 API가 주는 경로만 사용 |
| 입력 | 출발지, 도착지를 지번 또는 도로명 주소로 입력 |
| 실시간 도착 정보 | 소요 시간에는 반영하지 않음. 카카오 경로 API의 소요 시간에 승차 1회당 고정 대기 시간을 더해 사용 (`rules.md` 3.3). 버스, 지하철의 실시간 위치는 카드에 표시만 함 (권장 F-26, 2026-10-20 사용자 결정) |
| 추천 결과 | 기본 경로, 따릉이 포함 경로, 버스 전용 경로, PM 전용 경로 최대 4개 |
| 표시 순서 | 기본 경로가 1순위. 나머지는 총 소요 시간이 짧은 순. 같으면 버스 전용, 따릉이 포함, PM 전용 순 |
| 기본 경로의 PM 절감 시간 | 첫, 마지막 도보 구간을 킥보드 속도로 이동할 때 줄어드는 시간. 도보 구간은 카카오 도보 경로로 조회 (`rules.md` 3.2) |
| 따릉이 포함 경로 | First mile(출발지 → 첫 지하철 승차역), Last mile(마지막 지하철 하차역 → 도착지)을 따릉이로 대체. 지하철이 없는 경로는 첫, 마지막 버스 정류장을 같은 기준으로 사용. 표시 조건은 F-05 |
| 따릉이 데이터 | 서울 공공자전거 실시간 대여정보로 대여소, 재고 반영. 자전거 이동 시간은 카카오 자전거 경로(`SHORTEST`, 도심지 따릉이 이용 패턴 고려) |
| PM 전용 경로 | 카카오 자전거 경로(`route_mode` `SHORTEST`). 따릉이 대여소, 재고는 반영하지 않음 |
| 킥보드 | 이용 가능 여부를 다루지 않음. 기본 경로의 PM 절감 시간 계산에만 속도로 사용 |
| 개인 보정 | 출발, 도착 기록과 개인 소요 시간 보정은 권장. 경로 추천 시스템의 안정화, 고도화 이후 고려 |

## 1. 지향점

### 1.1 문제 정의
| ID | 문제 | 내용 |
|---|---|---|
| P-1 | 수단 판단 | 같은 출퇴근길에도 지하철, 버스, PM 중 무엇이 나은지 날마다 다르지만 한눈에 비교할 수 없음 |
| P-2 | 반복 입력 | 매일 같은 길인데도 길찾기를 할 때마다 출발지, 도착지를 다시 입력해야 함 |
| P-3 | 개인차 | 길찾기 서비스의 평균 기준 소요 시간이 나의 걸음, 자전거 속도, 환승 속도와 맞지 않음 |
| P-4 | 출발 시각 | 늦지 않으려면 몇 시에 나가야 하는지를 사용자가 직접 거꾸로 계산해야 함 |
| P-5 | 현장 변수 | 대여소에 도착해서야 따릉이가 없거나 반납할 자리가 없음을 알게 됨 |
| P-6 | 첫, 마지막 구간 | 대중교통 길찾기는 집에서 첫 역까지, 마지막 역에서 목적지까지를 도보나 버스로만 안내해, 그 구간을 PM으로 줄이는 선택지를 비교할 수 없음 |

### 1.2 서비스 정체성
| 축 | 의미 |
|---|---|
| 반복 경로 특화 | 출퇴근 장소를 한 번 저장하면 앱을 열 때마다 입력 없이 오늘의 추천 표시 |
| 대중교통과 PM의 비교 | 카카오 기본 경로를 기준으로 따릉이 포함, 버스 전용, PM 전용 경로를 함께 보여 줌 (주요 차별점) |

- 개인 학습(기록으로 예측 보정)은 경로 추천 시스템의 안정화, 고도화 이후 고려 (0.2)

## 2. 분류 기준

### 2.1 변수 1: 지향점 충족도
| 등급 | 의미 |
|---|---|
| 상 | 없으면 1.1의 문제 중 하나를 해결하지 못하거나 1.2의 서비스 정체성이 성립하지 않음 |
| 중 | 없어도 핵심 문제는 해결되지만 매일 쓰는 동안 불편하거나, 지속 사용과 신뢰를 높이는 데 기여 |
| 하 | 지향점과 관련이 적거나 서비스 원칙, 범위와 충돌 |

### 2.2 변수 2: 구현 난이도
- 기술 방식이 정해지기 전이므로 필요한 요소의 종류로만 대략 구분
| 등급 | 의미 |
|---|---|
| 낮음 | 화면과 기기 내 저장만으로 구현 가능 |
| 보통 | 외부 정보 한 종류(카카오 API 하나 또는 공공 데이터 하나) 또는 계산 규칙이 필요 |
| 높음 | 여러 외부 정보의 결합, 지도 연동, 서로 다른 출처의 이름, 위치 맞추기 중 하나 이상이 필요 |

## 4. 필수 기능 상세

### F-01 출퇴근 장소 등록 (주소, 장소 검색)
- 목적: 매일 같은 출발지, 도착지를 한 번만 입력
- 동작
  - 출발지(예: 집)와 도착지(예: 직장, 학교)를 지번 주소, 도로명 주소 또는 장소 이름(예: 강남역)으로 검색
  - 검색한 후보 목록에서 하나를 골라 확정. 확정한 주소는 좌표와 함께 저장
  - 출근은 출발지 → 도착지, 퇴근은 도착지 → 출발지로 자동 구성
  - 장소마다 알아보기 쉬운 이름 지정 (예: "집", "회사")
  - 등록한 장소의 수정, 삭제
- 원칙
  - 주소와 좌표는 사용자 기기에만 보관
  - 서버는 경로 조회를 위해 좌표를 받아 카카오에 전달하는 중계만 하고, 좌표와 주소를 저장하거나 기록에 남기지 않음

### F-02 출근, 퇴근 자동 전환
- 목적: 앱을 열었을 때 지금 필요한 방향의 추천을 바로 표시
- 동작
  - 앱을 연 시각에 따라 출근 또는 퇴근 방향의 추천을 기본으로 표시
  - 사용자가 한 번 눌러 반대 방향으로 전환 가능
- 전환 기준 시각과 설정 방식은 `rules.md`

### F-03 기본 경로 조회
- 목적: 카카오맵이 추천하는 경로를 비교의 기준으로 삼음
- 동작
  - 앱을 열 때와 사용자가 새로고침할 때 저장된 출발지, 도착지로 카카오 대중교통 경로를 조회
  - 카카오 추천 경로 원본을 기본 경로로 표시. 구간(도보, 버스, 지하철)의 순서, 구간별 거리와 소요 시간, 정류장 이름, 노선, 환승 횟수, 요금
- 카카오 응답에는 출발 시각 지정과 실시간 도착 정보가 없으므로, 소요 시간은 카카오 값에 승차 대기 시간을 더해 사용 (0.2)
- 기본 경로를 고르는 기준은 `rules.md`

### F-04 기본 경로의 PM 절감 시간 표시
- 목적: 별도 경로를 만들지 않고도 첫, 마지막 도보 구간을 PM으로 바꾸면 얼마나 빨라지는지 알려 줌
- 동작
  - 기본 경로의 출발 도보(출발지 → 첫 정류장), 도착 도보(마지막 정류장 → 도착지) 거리를 킥보드 속도로 이동할 때의 시간과 원래 도보 시간의 차이를 계산
  - 기본 경로 카드 옆에 줄어드는 시간을 표시 (예: "공유 모빌리티 탑승 시 7분 단축")
  - 출발 도보, 도착 도보의 거리, 시간은 카카오 도보 경로로 조회 (`rules.md` 3.2)
- 킥보드의 이용 가능 여부는 다루지 않음 (0.2)

### F-05 따릉이 포함 경로
- 목적: 첫, 마지막 구간을 따릉이로 바꾼 경로를 재고까지 확인해 제시
- First, Last mile 범위
  | 구간 | 범위 |
  |---|---|
  | First mile | 출발지 → 기본 경로의 첫 지하철 승차역. 그 사이의 도보, 버스 구간을 모두 포함 |
  | Last mile | 기본 경로의 마지막 지하철 하차역 → 도착지. 그 사이의 버스, 도보 구간을 모두 포함 |
  - 기본 경로에 지하철이 없으면 첫 버스 승차 정류장, 마지막 버스 하차 정류장을 같은 기준으로 사용
- 경로 구성: 구간 시작 → (도보) → 대여 대여소 → (따릉이) → 반납 대여소 → (도보) → 구간 끝
  - 대여 대여소는 대여 가능한 자전거가 있는 곳, 반납 대여소는 반납할 자리가 있는 곳만 선택
  - 카드에 대여 대여소 이름, 대여소까지 도보 시간, 대여 가능 대수를 함께 표시
- 표시 조건: 아래 중 하나라도 만족하면 표시
  | 조건 | 내용 | 표시하는 경로 |
  |---|---|---|
  | 조건 1 | 출발지에서 기본 경로의 첫 지하철역까지, 또는 마지막 지하철역에서 도착지까지 걸어서 20분 이상 (First, Last mile 대칭) | First, Last mile을 따릉이로 바꾼 경로 |
  | 조건 2 | First, Last mile을 따릉이로 바꾼 경로의 총 소요 시간이 기본 경로의 115% 미만 | First, Last mile을 따릉이로 바꾼 경로 |
  | 조건 3 | 대중교통 없이 출발지에서 도착지까지 따릉이로만 갈 때 30분 미만 | 조건 1, 2를 만족하지 않으면 전 구간 따릉이 경로 |
- 따릉이는 서울에만 있으므로, 구간 근처에 대여소가 없으면 그 구간은 바꾸지 않음
- 기준값, 대여소 반경, 시간 계산은 `rules.md`

### F-06 버스 전용 경로
- 목적: 지하철 없이 버스만 타는 선택지를 함께 보여 줌
- 동작: 카카오 대중교통 경로 중 버스만 타는 경로에서 총 소요 시간이 가장 짧은 경로를 표시
- 버스만 타는 경로가 없거나 기본 경로와 같은 경로이면 따로 표시하지 않음

### F-07 PM 전용 경로
- 목적: 대중교통 없이 PM만으로 가는 선택지를 함께 보여 줌
- 동작: 출발지에서 도착지까지 카카오 자전거 경로(최단 거리 방식)의 거리와 소요 시간을 표시
- 따릉이 대여소, 재고는 반영하지 않음. 킥보드, 개인 자전거 등 PM 전반의 기준 경로 (0.2)

### F-08 오늘의 추천 카드
- 목적: 최대 4개 경로를 한 화면에서 비교
- 동작
  - 기본 경로를 1순위로 맨 위에 강조
  - 나머지(따릉이 포함, 버스 전용, PM 전용)는 총 소요 시간이 짧은 순으로 아래에 표시
  - 카드마다 경로 종류 이름, 예상 도착 시각, 총 소요 시간, 구간 수단 요약(예: "따릉이 → 2호선 → 도보")을 표시
  - 기본 경로가 아닌 카드에는 기본 경로와의 시간 차이를 표시 (예: "기본 경로보다 6분 빠름")
- 순서 규칙의 세부는 `rules.md`

### F-09 추천 이유 표시
- 목적: 사용자가 각 경로의 특징을 납득하고 스스로 결정할 수 있도록 근거 제공
- 출력: 카드마다 핵심 근거 한 줄
  - 예: "출발지에서 첫 역까지 도보 22분 → 따릉이 8분", "대여소 자전거 3대", "환승 없음", "자전거로 25분"

### F-10 출발 시각 계산
- 목적: 늦지 않으려면 언제 나가야 하는지 직접 계산하지 않도록 함
- 동작
  - 목표 도착 시각과 여유 시간을 한 번 설정해 두면 매일 다시 입력하지 않음
  - 경로별로 "늦어도 출발해야 할 시각" 표시 (목표 도착 시각에서 예상 소요 시간과 여유 시간을 뺀 시각)
- 카카오 소요 시간에는 배차 대기 시간이 없어(`datasource.md` C-4) 승차 1회마다 고정 대기 시간을 더함 (`rules.md` 3.3)

### F-11 조회 실패, 정보 없음 처리
- 목적: 정보가 없을 때 추측으로 채우지 않음
- 동작
  | 상황 | 처리 |
  |---|---|
  | 카카오 대중교통 경로 조회 실패, 경로 없음 | 마지막으로 받은 결과와 받은 시각을 표시하고, 없으면 "경로를 찾지 못함" 안내. PM 전용 경로는 따로 표시 가능 |
  | 따릉이 대여정보 조회 실패 | 따릉이 포함 경로를 "재고 정보 없음"으로 표시 |
  | 따릉이 구간의 도보, 자전거 경로 조회 실패 | 따릉이 포함 경로를 표시하지 않음 |
  | PM 전용 경로의 자전거 경로 조회 실패 | PM 전용 경로를 표시하지 않음 |
- 세부 처리 순서는 `rules.md`

### F-12 저장 정보 모두 지우기
- 목적: 사용자 정보는 사용자가 통제한다는 서비스 원칙의 직접 구현
- 동작: 저장한 장소(주소, 좌표)와 설정을 한 번에 삭제. F-13, F-14 탑재 후에는 이동 기록과 개인 보정값도 함께 삭제. 실행 전 확인 절차를 거침

| F-20 | 출발 전 알림 | 화면이 열려 있는 동안 경로별 출발 시각 10분 전, 5분 전 알림 | F-10으로 출발 시각 문제는 해결되며, 알림은 실행을 돕는 보조 수단 |

| F-23 | 주간 리포트 | 경로 종류별 선택 횟수, 평균 소요 시간, 예측 오차를 그래프로 표시 | F-13 탑재 후 사용. 예측 정확도와 PM 효과를 확인해 신뢰를 높임 |

| F-25 | 홈 화면에 추가 | 휴대폰 홈 화면에 아이콘을 추가해 앱처럼 실행 | 매일 여는 서비스의 진입을 단축. 없어도 브라우저로 사용 가능 |
| F-26 | 버스, 지하철 실시간 위치 표시 | 경로 카드의 모든 버스, 지하철 구간에 승차 정류장, 역 기준 가장 가까운 차량의 상대 위치(N정거장 전, N역 전) 표시. 화면을 열 때, 새로고침할 때만 조회. 소요 시간, 출발 시각에는 반영하지 않음 | 카카오 경로 응답에 정류장 ID가 없어 공공 실시간 정보와 이름, 좌표로 맞춰야 해 난이도가 높음. 사용자 결정으로 권장 (2026-10-20) |
